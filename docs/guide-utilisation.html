Guide d'utilisation de Scrabble3D

De l'installation à la partie en réseau : tous les réglages, les aides au jeu et les règles d'arbitrage du Règlement international du Scrabble classique (FISF).

1. Présentation

Scrabble3D est un jeu de Scrabble pour Windows, Linux, macOS et Android. On y joue seul contre l'ordinateur, à plusieurs sur le même appareil ou en réseau, sur un plateau classique en 2D ou sur un cube en 3D.

Règles officiellesTirage au sort, temps épuisé, contestation, sanctions, abandon, feuille de match.
AidesIndice en deux temps, ordinateur à quatre niveaux, bilan de fin de partie.
Coach IAExplications des meilleurs coups et définitions, avec Groq, Gemini, Anthropic ou OpenCode.
DictionnaireFrançais par défaut, mises à jour, import de nouvelles listes de mots.

2. Installation

Paquet portable (zip)

  1. Récupérez le fichier Scrabble3D-<version>-windows.zip.
  2. Décompressez-le où vous voulez, par exemple dans Documents.
  3. Lancez Scrabble3D.exe dans le dossier Scrabble3D. Il n'y a rien à installer : Qt et toutes les bibliothèques nécessaires sont dans le dossier.

Installateur Windows (recommandé)

Le fichier Scrabble3D-<version>-setup.exe (par exemple Scrabble3D-4.0.13-setup.exe, environ 29 Mo) installe le jeu comme n'importe quel logiciel Windows.

  1. Lancez Scrabble3D-4.0.13-setup.exe par un double-clic.
  2. Avertissement de Windows. L'installateur n'est pas signé numériquement : Windows SmartScreen peut afficher « Windows a protégé votre ordinateur ». Cliquez sur Informations complémentaires, puis sur Exécuter quand même.
  3. Mode d'installation. Choisissez Installer pour tous les utilisateurs (droits d'administrateur demandés, dans Program Files) ou Installer pour moi uniquement (sans droits d'administrateur, dans votre profil).
  4. Langue de l'assistant : Français ou English.
  5. Dossier de destination : gardez celui proposé, ou choisissez-en un autre avec Parcourir.
  6. Tâches supplémentaires : cochez Créer une icône sur le Bureau si vous le souhaitez. Le raccourci du menu Démarrer est toujours créé.
  7. Installer, puis Terminer. Laissez cochée la case Exécuter Scrabble3D pour lancer le jeu tout de suite.
EnsuiteComment
Lancer le jeuMenu Démarrer > Scrabble3D, ou l'icône du Bureau.
Mettre à jourLancez l'installateur de la nouvelle version : il remplace l'ancienne au même endroit. Vos réglages, dictionnaires et parties sont conservés.
DésinstallerParamètres > Applications > Applications installées > Scrabble3D > Désinstaller, ou menu Démarrer > Scrabble3D > Désinstaller Scrabble3D.

La désinstallation retire le programme mais pas vos données : réglages, dictionnaires, parties et feuilles de match restent dans %LOCALAPPDATA%\Scrabble3D, et les clés du coach restent dans le gestionnaire d'identifiants de Windows. Supprimez-les vous-même si vous voulez tout effacer (voir §11).

Fabriquer l'installateur

Il faut Inno Setup 6 (gratuit), installable en une commande :

winget install JRSoftware.InnoSetup

Le script deploy\package-windows.ps1 (voir plus bas) produit alors dans dist\ le dossier portable, le zip et Scrabble3D-<version>-setup.exe. La version est lue dans version.h, et la description de l'installateur se trouve dans deploy\scrabble3d.iss.

Compiler depuis les sources

Il faut Qt 6.10 avec le compilateur MinGW 64 bits (installés par le Qt Online Installer, par exemple dans C:\Qt).

git clone https://github.com/simonet85/Scrabble3D.git
cd Scrabble3D
set PATH=C:\Qt\6.10.3\mingw_64\bin;C:\Qt\Tools\mingw1310_64\bin;%PATH%
mkdir ..\Scrabble3D-build && cd ..\Scrabble3D-build
qmake ..\Scrabble3D\QScrabble.pro
mingw32-make -j2
release\Scrabble3D.exe

Pour fabriquer vous-même le paquet portable et le zip (plus l'installateur si Inno Setup 6 est installé) :

powershell -ExecutionPolicy Bypass -File deploy\package-windows.ps1

Le résultat est rangé dans dist\. Avec -SkipBuild -BuildDir <dossier>, le script réutilise une compilation existante.

Premier lancement

  1. Dictionnaire. Le dictionnaire français est celui par défaut. S'il n'est pas encore sur l'ordinateur, le jeu propose de le télécharger : acceptez.
  2. Langue. Choisissez le français dans Configuration > Configuration... > Langue (téléchargement de la traduction si besoin).
  3. Mises à jour. Une fois par semaine, le jeu vérifie seul s'il existe des dictionnaires ou des traductions plus récents.
  4. Première partie. Partie > Nouvelle partie (Ctrl+N), puis OK.

3. L'écran de jeu

ChevaletVos lettres, à glisser sur le plateau. Les boutons à côté permettent de mélanger, de rappeler les tuiles posées, d'échanger et de demander un indice.
Onglet MessagesTout ce qui se passe : coups joués, Scrabble, jokers, sanctions, erreurs. Un point rouge signale un nouveau message.
Onglet Fil de jeuChaque coup avec ses points, le meilleur coup possible et le temps utilisé.
Onglet JoueursLes joueurs connectés, en réseau seulement.
Onglet CoachLes réponses du coach IA et le bilan de partie. Un point rouge signale une nouvelle réponse.

Configuration > Mode d'affichage passe de la mise en page Bureau (paysage) à Mobile (portrait, avec les onglets en bas de l'écran, Coach compris), ou laisse le jeu choisir (Automatique) selon la forme de la fenêtre.

4. Jouer une partie

Lancer la partie

Partie > Nouvelle partie ouvre le dialogue de départ : de 1 à 4 joueurs, chacun humain ou ordinateur, et un résumé des réglages en cours (plateau, lettres, dictionnaire, temps, vérification des mots).

  • Tirer une lettre pour savoir qui commence (§2.1) : chaque joueur tire une lettre et le plus proche du A commence ; les jokers ne comptent pas et les ex æquo tirent à nouveau.
  • Ordre aléatoire : mélange l'ordre des joueurs.

5. Paramétrage

Tous les réglages sont dans Configuration > Configuration... et sont gardés d'une session à l'autre. Ils s'appliquent à la prochaine partie.

Plateau et son

RéglageEffet
ModèleClassique, Superscrabble, Superscrabble 3D ou plateau personnalisé.
Dimension, taille2D ou 3D (cube), nombre de cases par côté.
Cases primesCliquez sur une case pour faire défiler ses types (plateau personnalisé).
Marqueurs, couleursRepères des cases primes, couleurs des cases et des joueurs.
SonSon joué lors d'un Scrabble, volume, bouton Tester.

Lettres

Jeu de lettres et répartition (lettre, points, nombre), nombre de jokers, nombre de lettres sur le chevalet (7 en classique), lettres aléatoires et sens de lecture.

Dictionnaire

Liste des dictionnaires avec leur version installée et la version disponible : Charger, Télécharger, Supprimer. Les catégories permettent d'ajouter ou de retirer des familles de mots. Si la répartition des lettres du dictionnaire ne correspond pas à celle de la configuration, le jeu propose de l'adopter.

Temps

RéglageEffet
Contrôle du tempsSans limite, par coup ou par partie (pendule).

Pénalité sur temps écoulé« Acheter » une minute contre des points, un nombre limité de fois.

Temps épuisé (pendule par partie). Les tuiles posées au moment où le temps s'écoule reviennent au chevalet (§4.5). Le joueur passe ensuite automatiquement à chacun de ses tours, mais seulement après la période de contestation : il peut donc encore contester le dernier coup. Ses adversaires ne peuvent plus échanger de lettres. Un message l'annonce une seule fois.

Vérification des mots

ModeFonctionnement
RepriseLe jeu vérifie le coup et demande confirmation si un mot est inconnu.
SondageTous les joueurs du groupe confirment un mot absent du dictionnaire.
ContestationUn joueur doit contester le coup pendant la période (en secondes). Pénalité si le mot est accepté, bonus s'il est refusé ; la pénalité peut être multipliée par le nombre de mots contestés à tort.

Langue

Télécharger, charger ou supprimer une traduction de l'interface. Les textes ajoutés dans cette version (coach, indice, sanctions, feuille de match…) sont déjà traduits en français.

6. Aides au jeu

Indice

Le bouton Indice (n) à côté du chevalet, ou Partie > Indice, fonctionne en deux temps :

  1. Premier indice du tour : la valeur d'un bon coup, le nombre de tuiles qu'il utilise et sa première case, encadrée en jaune.
  2. Deuxième indice du même tour : le mot, avec toutes ses cases encadrées.

Chaque indice compte, dans la limite fixée dans Règles > Indices par partie. Les indices sont proposés dans une partie 2D hors réseau, quand c'est le tour d'un joueur humain.

Niveaux de l'ordinateur

NiveauJeu
DébutantDes coups ordinaires.
IntermédiaireUn des meilleurs coups.
AvancéTient compte aussi des lettres qu'il garde.
MaîtreLe meilleur équilibre entre points et lettres gardées, et il évite d'ouvrir à l'adversaire les cases « mot compte double ou triple ».

Coach IA

Le coach explique les meilleurs coups et donne la définition des mots joués. Il ne fait que conseiller : seul le dictionnaire décide si un mot est valide.

  1. Obtenez une clé d'API chez l'un des services : Groq (par défaut), Gemini, Anthropic ou OpenCode.
  2. Configuration > Coach IA... : choisissez le service, collez la clé, changez le modèle si besoin, puis Enregistrer.
  3. À la première demande, le jeu vous demande votre accord pour envoyer le plateau, votre chevalet et les meilleurs coups au service choisi. Rien n'est envoyé tant que vous ne sollicitez pas le coach.
  4. Utilisez Partie > Coach : expliquer les meilleurs coups ou Coach : définir les derniers mots. Les réponses s'affichent dans l'onglet Coach.

Dans l'onglet Coach, deux options :

  • Conseil à chacun de mes tours : le coach analyse votre chevalet au début de votre tour.
  • Noter mon meilleur coup à chaque tour : nécessaire au bilan de partie. Rien ne s'affiche pendant la partie.

Sécurité des clés. Sous Windows, les clés sont chiffrées dans le gestionnaire d'identifiants de Windows (« Scrabble3D coach/… »), et non en clair dans coach.ini. Une clé d'une version précédente y est déplacée automatiquement. Supprimer la clé enregistrée l'efface aussi du gestionnaire.

Le service peut facturer l'utilisation de votre clé. Gemini est parfois lent ou saturé ; OpenCode demande des crédits ou un abonnement. Le message d'erreur du service s'affiche dans l'onglet Coach.

Bilan de partie

Une fois la partie terminée, Partie > Bilan de partie compare chacun de vos coups au meilleur coup possible à ce tour, dans l'onglet Coach. Il faut avoir activé Noter mon meilleur coup à chaque tour pendant la partie. Un coup défensif, volontairement moins payant, y apparaît comme une perte.

7. Arbitrage et fin de partie

Sanctions (§6.4)

Partie > Sanction... : choisissez le joueur et décrivez l'infraction. Le dialogue annonce la sanction qui s'applique. Le barème est compté par joueur :

InfractionSanction
1reRappel du règlement
2e (1re récidive)5 points de pénalité
3e50 points de pénalité
4eMatch perdu : score mis à 0, fin de la partie

Chaque sanction est annoncée dans les messages et reprise sur la feuille de match. Les compteurs repartent à zéro à chaque nouvelle partie.

Abandon (§4.11)

Partie > Abandonner (deux joueurs, au moins un coup joué) : l'adversaire doit donner son accord. Scores retenus : si l'écart est d'au plus 100 points, 350 pour celui qui abandonne et au moins 450 pour le gagnant ; sinon, chacun garde son score, avec au moins 450 pour le gagnant.

Décompte de fin de partie

La partie s'arrête quand un joueur vide son chevalet et que le sac est vide, ou après le nombre de passes consécutives fixé. Chaque joueur perd la valeur de ses lettres restantes. Seul le joueur qui a vidé son chevalet reçoit la valeur des lettres de ses adversaires : une partie finie par des passes ne fait que retirer des points. Le message de fin rappelle les scores, l'écart plafonné à 100 points et la liste des jokers joués.

8. Feuille de match

Partie > Exporter la feuille de match..., puis choisissez le format avec l'extension du fichier :

PDFÀ imprimer et à signer.
CSVPour un tableur (séparateur point-virgule, accents conservés).
Page webUn fichier HTML lisible dans un navigateur.

La feuille contient chaque coup avec le cumul du joueur, les ajustements de fin de partie, les scores finaux, l'écart plafonné à 100 points (§5.3), le vainqueur, les jokers avec la lettre représentée (§1.1.5), les sanctions et leur motif, et une ligne de signature par joueur.

9. Dictionnaire et mises à jour

Recherche de mots

Configuration > Recherche de mots : l'onglet Rechercher vérifie un mot et affiche sa catégorie et son sens ; l'onglet Motif trouve les mots qu'on peut former avec des lettres données.

Importer une liste de mots

Configuration > Importer une liste de mots... ajoute au dictionnaire en cours les mots d'un fichier texte (un mot par ligne, par exemple une nouvelle édition de l'ODS). Les accents et les ligatures sont retirés, et les lignes inutilisables sont ignorées. L'ancien dictionnaire est sauvegardé (.bak-date) et le rapport s'affiche dans les messages.

Mises à jour

Aide > Rechercher des mises à jour lit la liste officielle du serveur. Le jeu propose alors les dictionnaires et traductions plus récents, ou annonce que tout est à jour. Il fait aussi cette vérification seul une fois par semaine.

Vos mots importés sont gardés à part, dans <dictionnaire>.imported.txt. Quand une nouvelle édition officielle remplace le dictionnaire, ils y sont ajoutés de nouveau automatiquement.

10. Jeu en réseau

  1. Partie > Se connecter au serveur de jeu : saisissez le serveur (par défaut scrabble3d.ignorelist.com:5001), votre nom, votre mot de passe, votre adresse e-mail, votre pays et votre ville.
  2. Formez un groupe en invitant des joueurs depuis l'onglet Joueurs. Discutez avec le champ de saisie sous les onglets (/help pour l'aide).
  3. Celui qui lance la partie envoie sa configuration à tout le groupe ; les autres l'acceptent.
AdresseConnexion
hôte, hôte:port, tcp://hôte:portEn clair, comme le serveur public actuel : n'utilisez pas un mot de passe qui sert ailleurs.
tls://hôte:portChiffrée (TLS). Rien n'est envoyé avant la poignée de main ; un certificat invalide ou un serveur sans TLS est refusé. Il faut un serveur ou un relais (stunnel, par exemple) qui propose TLS.

Si tous les joueurs du groupe ont cette version, l'abandon avec accord de l'adversaire et le tirage au sort du premier joueur fonctionnent aussi en réseau. Face à une version plus ancienne, ces deux fonctions restent inactives et la partie se déroule comme avant.

ProblèmeSolution
